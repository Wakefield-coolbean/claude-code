# Skin Totems

Ever seen those custom totem resource packs where the totem looks like a player? This does that automatically, for everyone, using their actual skin.

## What it does

Whenever someone is holding a Totem of Undying, it gets swapped for a little figure built from that player's skin. Head, shirt, arms, legs, all pulled straight from whatever skin they're wearing. Your totem looks like you, your friend's looks like them, and the random guy you're fighting on a server looks like him.

No resource pack needed, and nobody else has to have the mod installed. It just reads the skins your game already has.

## Details

- Works in both hands, first person and third person
- Supports classic and slim (Alex) arm skins
- Picks up the outer skin layers like hats and jackets
- Only held totems change. In your inventory, hotbar, on the ground or in item frames they look like normal totems
- Client side only, works on any server

## Requirements

- Minecraft 1.21.11
- Fabric Loader
- Fabric API

## Issues

If something looks off (weird edges, wrong position in your hand, a skin that doesn't show up right), open an issue with a screenshot and I'll take a look.
